# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Babel](https://babeljs.io/) (or [oxc](https://oxc.rs) when used in [rolldown-vite](https://vite.dev/guide/rolldown)) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/) for Fast Refresh

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

# GameHub

## Project Purpose
GameHub is a comprehensive platform for mobile gamers to discover, download, and discuss the best mobile games**. It aims to connect gamers and developers in a community-driven environment with curated game collections, real user ratings, and fast downloads.

## Live URL
(https://cheerful-hamster-d6b411.netlify.app/)

## Key Features
- 🎮 **Curated Game Collection**: Hand-picked mobile games from top developers.  
- ⭐ **Quality Ratings**: Real user reviews you can trust.  
- 🚀 **Fast Downloads**: Secure and quick download options.  
- 💬 **Community Driven**: Join discussions and share your gaming experience.  
- 📬 **Newsletter Subscription**: Stay updated with latest releases and updates.  
- 📊 **Game Statistics**: View key metrics like number of games, happy gamers, developers, and support availability.  
- 👥 **Team Showcase**: Meet the team behind GameHub.

## NPM Packages Used
- [framer-motion] – For animations and motion effects.  
- [react router] – UI library for building components.  
- [tailwindcss] – Utility-first CSS framework for styling.  
- [daisyUI] – For prebuilt Tailwind components like buttons, badges, inputs.
